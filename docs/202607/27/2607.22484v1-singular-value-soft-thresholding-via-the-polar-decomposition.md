## 摘要
奇异值软阈值可以通过归约到矩阵极分解来计算，这使得可以利用GPU友好的算法来计算极分解。实验表明，与使用SVD的标准方法相比，在GPU上有显著的加速。我们将鲁棒性的研究留待未来工作，但注意到由于符号函数的不连续性，归约到极分解可能仅适用于低精度应用。

## Abstract
Singular value soft-thresholding can be computed via a reduction to the matrix polar decomposition, which allows one to exploit GPU-friendly algorithms for computing the polar decomposition. Empirically, there is a significant speed-up on GPUs compared to the standard approach using the SVD. We leave the investigation of robustness to future work, but note that due to the discontinuous nature of the sign function, the reduction to the polar decomposition is likely only suitable for low-accuracy applications.

### 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：奇异值软阈值（Singular Value Soft-Thresholding, SVST）是许多优化算法（如核范数近端梯度法）的关键子程序，传统上通过奇异值分解（SVD）计算。然而，SVD 在 GPU 上通信开销大、效率低，限制了大规模矩阵的处理速度。
- **研究动机**：近年来，矩阵极分解（Polar Decomposition）可通过通信友好的迭代算法（如 Newton-Schulz 方法、Polar Express）在 GPU 上高效计算，且主要成本为矩阵乘法，适合 GPU 加速。本文提出将 SVST 归约到极分解，从而利用 GPU 友好的极分解算法实现加速。
- **整体含义**：为低精度应用（如某些神经网络训练）提供了一种比传统 SVD 更快的替代方案，尤其适合 GPU 环境。

### 2. 方法论：核心思想、关键技术细节与算法流程
- **核心思想**：利用恒等式 \((\lvert x \rvert + x)/2 = \max(x,0)\)，将 SVST 表达为极分解的代数组合。
- **关键技术细节**：
  - 给定矩阵 \(A\) 的 SVD \(A = U\Sigma V^\top\)，极分解 \(P = UV^\top\)。
  - 定义 \(S = \text{polar}(A^\top A - \tau I_n)\)，其中 \(\tau\) 为阈值。
  - 命题1：奇异值软阈值 \(A_\tau = \frac{1}{2}(A + AS) - \frac{\tau}{2}(P + PS)\)。
  - 类似地，若 \(n > m\) 可采用对称形式 \(A_\tau = \frac{1}{2}(A + SA) - \frac{\tau}{2}(P + SP)\)，其中 \(S = \text{polar}(AA^\top - \tau I_m)\)。
- **算法流程**（以 \(m \leq n\) 为例）：
  1. 计算极分解 \(P = \text{polar}(A)\)。
  2. 计算 \(S = \text{polar}(A^\top A - \tau^2 I_n)\)（注意原文中使用了平方，但公式表述为 \(A^\top A - \tau I\)，实际代码中为 \(A^\top A - \tau^2 I\)）。
  3. 计算 \(Y = (A + A S)/2 - (\tau/2)(P + P S)\)，返回 \(Y\)。
- **可选精度**：极分解迭代次数可调（如 20 次），低精度下显著加速。
